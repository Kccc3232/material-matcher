# 📦 料号自动匹配器

根据总档案文件的品名/规格等信息，自动匹配并补全料号。**纯浏览器端运行，数据不上传服务器。**

## 使用方法

1. 打开 [网页版](https://kccc3232.github.io/material-matcher/)
2. 拖入或选择**总档案文件**（含完整料号信息）
3. 拖入或选择**待匹配文件**（需补料号）
4. 选择目标字段，点击「开始匹配」
5. 下载结果 Excel

## 功能

- 🎯 **可选目标字段**：料号 / 品名 / 规格 / 参考料号
- 🔍 **可选匹配条件**：自由勾选用哪些字段去匹配
- 📎 **合并列头支持**：如「规格/参考料号」自动识别
- 🔤 **模糊匹配**：条件对不上时按相似度匹配
- 🎨 **输出美化**：表头样式、隔行变色、自动列宽、冻结首行、自动筛选
- 🔵 **颜色区分**：品名/料号匹配→黑色、规格匹配→蓝色、模糊/参考料号匹配→红色

## 支持的文件格式

.xlsx / .xls / .csv

## 本地运行

下载 `index.html` 双击打开即可使用（首次需联网加载库文件，之后可离线）。
